# StokKasir V3

Project Android offline-first untuk stok + kasir.

Fitur V3:
- UI 4 tab: Stok, Kasir, Laporan, Info.
- Produk: nama, kategori, satuan, barcode, harga modal, harga jual, stok, batas minimum, keterangan.
- Pencarian nama/kategori/barcode.
- Kasir dengan keranjang, jumlah, total, pembayaran, kembalian.
- Checkout membuat invoice dan otomatis mengurangi stok.
- Restock otomatis membuat transaksi barang masuk.
- Riwayat transaksi.
- Omzet dan ringkasan bulan berjalan.
- Tanda stok menipis.
- Database lokal Room.
- Timestamp mengikuti tanggal/jam perangkat.

Catatan:
V3 ini adalah fondasi aplikasi produksi. Fitur kamera/foto, scanner barcode kamera, export Excel/PDF, backup/restore, PIN, laporan periode bebas, dan grafik dapat ditambahkan sebagai V3.1/V4. Struktur database sudah disiapkan agar fitur tersebut mudah disambungkan.
